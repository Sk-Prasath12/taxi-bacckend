6. Order history & history with route

List (ride history)

GET /booking/orders?limit=20&offset=0&status=COMPLETED

Add &includeRoute=true to get routePolyline or routeCoordinates per order for the map.

Single order with route

GET /booking/orders/:id?includeRoute=true

Returns one order with full route (pickup, drop, polyline/coordinates) for ride detail screen.

Storage: Store route_polyline (encoded or JSON array of [lat,lng]) on the order table when trip is completed or route is computed.
